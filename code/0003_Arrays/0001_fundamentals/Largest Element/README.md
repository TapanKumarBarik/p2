# Largest Element

Given an array of integers `nums`, return the value of the largest element in the array.

## Example 1

**Input:**
```text
nums = [3, 3, 6, 1]
```

**Output:**
```text
6
```

**Explanation:**

The largest element in the array is `6`.

## Example 2

**Input:**
```text
nums = [3, 3, 0, 99, -40]
```

**Output:**
```text
99
```

**Explanation:**

The largest element in the array is `99`.

## Constraints

- `1 <= nums.length <= 10^5`
- `-10^4 <= nums[i] <= 10^4`
- `nums` may contain duplicate elements.
