# Pattern 4


Given an integer `n`. You need to recreate the pattern given below for any value of N. Let's say for N = 5, the pattern should look as below:

```text
1
22
333
4444
55555
```

Print the pattern in the function given to you.

## Example 1

**Input:**
```text
n = 4
```

**Output:**
```text
1
2 2
3 3 3
4 4 4 4
```

## Example 2

**Input:**
```text
n = 2
```

**Output:**
```text
1
2 2
```

## Constraints

- `1 <= n <= 100`
