# Pattern 19

## Problem Statement

Given an integer `n`. You need to recreate the pattern given below for any value of `N`.

Let's say for `N = 5`, the pattern should look like this:

```text
**********
**** ****
***   ***
**     **
*       *
*       *
**     **
***   ***
**** ****
**********
```

Print the pattern in the function given to you.

## Example 1

**Input:** `n = 4`

**Output:**

```text
********
***  ***
**    **
*      *
*      *
**    **
***  ***
********
```

## Example 2

**Input:** `n = 2`

**Output:**

```text
****
*  *
*  *
****
```

## Constraints

- `1 <= n <= 100`
