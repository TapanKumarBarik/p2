# Print Name N Times Using Recursion

## Problem Description

Given an integer `N`, write a program to **print your name `N` times using recursion**.

## Examples

### Example 1

**Input:**
```text
N = 3
```

**Output:**
```text
Ashish Ashish Ashish
```

**Explanation:**  
The name is printed `3` times.

### Example 2

**Input:**
```text
N = 1
```

**Output:**
```text
Ashish
```

**Explanation:**  
The name is printed once.
