# Switch Case

Given the integer `day` denoting the day number, print on the screen which day of the week it is.

The week starts from **Monday**. For values greater than `7` or less than `1`, print **Invalid**.

Ensure only the **1st letter** of the answer is capitalised.

### For printing use:-

- **C++:** `cout << variable_name;`
- **Java:** `System.out.print();`
- **Python:** `print()`
- **Javascript:** `console.log()`

### Example 1

**Input:** `day = 3`  
**Output:** `Wednesday`

### Example 2

**Input:** `day = 8`  
**Output:** `Invalid`

### Example 3

**Input:** `day = 2`  
**Output:** `Tuesday`

### Constraints

- `0 <= day <= 50`
