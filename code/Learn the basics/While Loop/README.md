
# Sum of First 50 Positive Integers Ending With Digit `d`

Given a digit `d` (0 to 9), find the sum of the first **50 positive integers** (integers > 0) that end with digit `d`.

A number ends with digit `d` if its last digit is `d`.

## Example 1

**Input:**
```text
d = 1
```

**Output:**
```text
12300
```

**Explanation:**

The first 50 positive integers ending with `1` are:

```text
1, 11, 21, 31, ... , 491
```

Their sum is:

```text
12300
```

## Example 2

**Input:**
```text
d = 5
```

**Output:**
```text
12500
```

## Constraints

```text
0 <= d <= 9
```
